# Kanban

A single project board with five columns. Cards have a title and details. Drag a card by its yellow bar to reorder it or move it between columns. Click a column name, card title, or card details to rename it. Add and delete cards. Refreshing the page restores the sample board.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Test

```bash
npm test
npm run test:e2e
```
