# Antigravity Kanban

Client-rendered single-board Kanban application built with Next.js, React, and TypeScript.

## Requirements

- Node.js 18+ (tested on Node 26)
- npm 9+

## Setup

```bash
npm install
```

## Running the Application

```bash
npm run dev -- --port 3200
```

The application runs at http://localhost:3200.

## Testing

Run unit tests:

```bash
npm test
```

Run Playwright integration tests:

```bash
npm run test:e2e
```

Run linter and typecheck:

```bash
npm run lint
npm run typecheck
```

## Production Build

```bash
npm run build
npm run start
```
